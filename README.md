# Laugh Track: The Crypto Trading Joke Contest

One line, under 200 characters, about crypto and trading life — for the
make.fun bounty `u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a`
($2, top 10; closes 2026-11-26T20:50:00Z). A judge model reads entries two at
a time and picks the funniest.

## The entry

`main.ts` (Node 22, stdlib only, no network) writes exactly one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I bought the dip, then the dip bought a shovel and kept digging.

64 characters — inside the sealed scorer's 1–200 character UTF-8 gate, with a
clear setup ("I bought the dip") and a surprise turn (the dip fights back
with a shovel and keeps digging), true to trading life: every dip-buyer has
watched the chart fall further after buying.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-out node main.ts
cat /tmp/laugh-out/entry.txt
```
